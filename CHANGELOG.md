# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.0] - 2026-06-21

### Added

- GitHub Actions quality gate for format, types, lint, coverage, audit, and build.
- Automated axe accessibility tests and explicit `jsx-a11y` lint rules.
- Accessible data-table equivalents for carbon breakdown and projection charts.
- Strict API body limits, validation, safe error responses, and isolated rate limits.
- Non-root multi-stage Docker deployment with a health check.
- `/api/health` readiness endpoint.
- Architecture and contribution documentation.

### Changed

- Expanded unit, integration, security, and branch coverage.
- Strengthened Content Security Policy and browser security headers.
- Added skip-link, reduced-motion, focus-visible, live-region, and busy-state support.

## [0.1.0] - 2026-06-21

### Added

- Deterministic carbon footprint engine and five Carbon Aura classifications.
- Personalized Gemini narrative and AI coach with deterministic fallbacks.
- Habit simulator, purification quests, decade projections, and consequence views.
- Local-first persisted profile with no account or analytics requirement.
